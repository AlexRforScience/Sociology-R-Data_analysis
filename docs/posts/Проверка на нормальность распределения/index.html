1 Нормальность распределения

Мы можем проверить гипотезу о нормальности распределения с помощью двух статистических тестов, Шапиро-Уилка и более строгого теста Колмогорова-Смирнова, за \(a\) возьмем значение 0.05.

Выбор критерия

Если компьютер может вычислить Шапиро-Уилка, то считаем Шапиро-Уилка, если не может, то применяем Колмогорова-Смирнова.

Создадим в R вектор чисел, имеющих нормальное распределение

set.seed(123)
x <- rnorm(1000, 0, 1)
hist(x, col = "lightblue", border = "black")

Далее, применим тест Шапиро-Уилка (\(a=0.05\)) и посмотрим на результат:

shapiro.test(x)

    Shapiro-Wilk normality test

data:  x
W = 0.99838, p-value = 0.4765

Полученный результат \(p-value > a\), а значит основную гипотезу о нормальности распределения не отвергаем.

Попробуем обратиться к тесту Колмогорова-Смирнова:

ks.test(x, "pnorm")

    Asymptotic one-sample Kolmogorov-Smirnov test

data:  x
D = 0.019416, p-value = 0.8452
alternative hypothesis: two-sided

Полученный результат \(p-value >a\), а значит основную гипотезу о нормальности распределения не отвергаем. Как было сказано ранее, тест Колмогорова-Смирнова слишком строгий, например, если мы зададим иной set.seed, то Шапиро-Уилка все еще не отвергнет гипотезу о нормальном распределении, а вот тест Колмогорова-Смирнова уже отвергнет нулевую гипотезу для \(a=0.05\):

set.seed(145)
x <- rnorm(1000, 0, 1)
shapiro.test(x) # p-value > 0.05

    Shapiro-Wilk normality test

data:  x
W = 0.99816, p-value = 0.3542
ks.test(x, "pnorm") # p-value < 0.05

    Asymptotic one-sample Kolmogorov-Smirnov test

data:  x
D = 0.045415, p-value = 0.03232
alternative hypothesis: two-sided

Это говорит о том, что после использования теста Колмогорова-Смирнова необходимо визуализировать распределение переменной, а также попробовать воспользоваться другими тестами, например Шапиро-Уилка, чтобы избежать ошибку II рода.

Критериев очень много

Сборник критериев нормальности распределения содержится в пакете “nortest”, но на практике все же чаще всего используют Шапиро-Уилка тест! Не стоит забивать голову множеством критериев, так как это парализует любую деятельность.

2 Нужна ли нормальность?

Ряд методов, которые предполагают нормальность распределения, могут работать, когда распределение данных несущественно отличается от нормального.

Существенные отклонения:

  1. Наличие выбросов в данных

  2. Явная асимметрия гистограммы

  3. Очень сильное отклонение формы гистограммы от колоколообразной формы

Рекомендуется:

  • строго относится к присутствию выбросов

  • снисходительно к отклонениям от симметрии

  • если число наблюдений меньше 30, то относимся к отклонениям от колоколообразной формы в высшей степени либерально; если число наблюдений от 30 до 150, то относимся снисходительно; если наблюдений больше 150 - строго

Как приблизить к нормальности:

  • Выбросы - удаляем (осторожно!)

  • Асимметрия - преобразуем данные (логарифмируем, преобразование Бокса-Кокса)

  • Бимодальность - разбиваем выборку на подвыборки

Удалять выбросы нужно на свой страх и риск, всё очень ситуативно, если выбросы - это результат технической ошибки измерения, то конечно их стоит удалять, но если ситуация другая, то удалять нужно с особой осторожностью, так как это может привести к потери важной информации.

Для преобразования в случае асиметрии воспользуемся одним из методов, а именно прологарифмируем переменную hp из датафрейма mtcars, а заодно проверим на нормальность распределения с помощью Шапиро-Уилка:

df <- mtcars
hist(df$hp, col = "lightblue", border = "black") # Визуально распределение не имеет нормального вида
hist(log(df$hp), col = "lightblue", border = "black") # Теперь распределение имеет нормальный вид
shapiro.test(df$hp) # p-value < 0.05

    Shapiro-Wilk normality test

data:  df$hp
W = 0.93342, p-value = 0.04881
shapiro.test(log(df$hp)) # p-value > 0.05

    Shapiro-Wilk normality test

data:  log(df$hp)
W = 0.97026, p-value = 0.5065

Таким образом, как визуально, так и с помощью результата теста Шапиро-Уилка, логарифмирование переменной hp из датафрейма mtcars привело ее распределение к нормальному виду (точнее - не отвергаем гипотезу о том, что логарифм распределения перемеменной имеет нормальный вид).

Стоит очень осторожно относится к преобразованиям переменной, так как очень часто это может исказить интерпретацию результатов использованных методов. Более подробно про преобразования смотрите в посте “преобразование переменных”.

Для обнаружения бимодальности необходимо визуализировать распределение переменной с помощью гистограммы. Для начала создадим искуственный датафрейм, где будет две колонки, числовая, состоящая из двух векторов с нормальным распределением, но разным средним и стандартным отклонением, а вторая колонка будет указывать, какие значения относятся к исходному распределению переменной x или y:

set.seed(15)
y <- rnorm(1000, 50, 4)
x <- rnorm(1000, 35, 5)
variable <- c(x, y)
group <- c(rep("x", 1000), rep("y", 1000))
df_new <- data.frame(variable = variable, group = group)

Теперь изобразим распределение колонки variable:

hist(df_new$variable, col = "lightblue", border = "black")

Уже визуально видно, что распределение колонки variable имеет ненормальный вид, видно, что оно состоит из двух колокообразных распределений. Тем не менее, проверим тестом Шапиро-Уилка (\(a=0.5\)), чтобы окончательно убедиться в отсутствии нормальности распределения:

shapiro.test(df_new$variable)

    Shapiro-Wilk normality test

data:  df_new$variable
W = 0.96285, p-value < 2.2e-16

Действительно, \(p-value < a\), а значит отвергаем гипотезу о нормальности распределения.

Конечно, наш пример искусственный, так что мы уже знаем, на какие две выборки должна быть разделена переменная, визуализируем с помощью ggplot2:

library(ggplot2)
ggplot(df_new)+
  theme_classic()+
  geom_density(mapping = aes(variable, fill = group, colour = group), alpha = 0.7)

Таким образом, указав цветом группу, мы увидели, что в нашей переменной содержатся два разных распределения, имеющие, вероятно, нормальный вид.

Проверим каждую группу с помощью теста Шапиро-Уилка:

shapiro.test(df_new$variable[df_new$group=="x"])

    Shapiro-Wilk normality test

data:  df_new$variable[df_new$group == "x"]
W = 0.99881, p-value = 0.7626
shapiro.test(df_new$variable[df_new$group=="y"])

    Shapiro-Wilk normality test

data:  df_new$variable[df_new$group == "y"]
W = 0.99728, p-value = 0.09025

Тест Шапиро-Уилка показал, что основаня гипотеза о нормальном распределении не отвергается как для x, так и для y.
